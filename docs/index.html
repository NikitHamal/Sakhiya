About Sakhiya-V1
Nepali and Sanskrit on-device speech in three clean tiers: Sakhiya-V1, Sakhiya-V1-Nano, and Sakhiya-V1-Atom.

  

    
database
Expressive + Vagdhenu Vedic Provenance
Sakhiya-V1 unifies Rasa Nepali expressive styles (HAPPY, SURPRISE, BOOK, CONV, NEWS), Rasa Sanskrit, and Vagdhenu studio Vedic chanting (CC-BY-4.0) into one canonical female voice via Neural VC.

Sakhiya-V1-Nano (4.4 MB) & Sakhiya-V1-Atom (1.8 MB)
Compact students distilled from Sakhiya-V1 with frozen MelCTCAligner pronunciation supervision and pitch-driven Source-Filter Harmonic iSTFT vocoders running ~46×–55× real-time on CPU.

music_note
Chandas · Laya · Svara
In Vedic Chant mode the text is split into aksharas, scanned as Laghu / Guru, matched to a meter (Gāyatrī, Anuṣṭubh, Triṣṭubh, Jagatī) and compiled into exact syllable durations (Laya BPM) and a just-intonation pitch line on the voice’s own tonic (about 215 Hz). The same code runs in Python and in your browser (chandas.js, parity tested). An optional tanpura drone is generated with WebAudio, with no audio file.

    
auto_awesome
Expression Cartridges
Sixteen tiny hand-designed presets (5.8 KB in total): News Crisp, Warm Folk Story, Excited वाह!, Gayatri 72 BPM, Rigveda Svara and more. Today they drive the speed, pause, tone and svara controls. You can also hum 3 seconds into the microphone to build your own; nothing leaves your device.

    
terminal
GGML C/C++ Standalone CLI (sakhiya-cli)
Compile a standalone native binary linked against ggml (CPU + optional CUDA / Vulkan / Metal) reading a single .gguf file (FP32 58.1 MB, FP16 40.0 MB, Q8_0 36.7 MB) with bit-exact PyTorch parity (cosine_sim = 1.000000, max_abs_diff < 1e-3 at every stage, ~12× real-time on CPU).

    
integration_instructions
Native C++ / Python / Android (sakhiya.cpp)
One zero-dependency C++17 engine and one C ABI (cpp/sakhiya.h) power sakhiya-cli, libsakhiya.so, the Android JNI wrapper, the Python wrapper and the sakhiya.wasm that runs this page. Single-file GGUF models (Atom-Lite Q8_0 3.0 MB · Atom 7.4 MB · Nano 10.1 MB · V1 37.5 MB) live on Hugging Face and the v15-ggml-gguf release.
